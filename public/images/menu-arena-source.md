# Main-menu artwork

`menu-arena.webp` is the background for the user's selected "Inside the arena" menu concept. The title and buttons are rendered separately in React.

Created with the built-in imagegen tool from the user-approved mockup, then encoded as WebP at quality 88 without resizing. The generated original remains in Codex's generated-images directory.

## Imagegen edit prompt

Preserve the exact 16:9 composition, the overhead geometric arena on the right, its camera angle, all cyan player/red square/purple triangle/yellow circular enemies, stone walls, projectiles, sparks, orange light, textures and dark cinematic palette. REMOVE ALL text, letters and UI: remove MEMORY ARENA, SURVIVAL, START RUN, LOAD SAVED RUN, and the entire orange rectangular button. Seamlessly fill their areas with the existing almost-black, lightly textured background. The left 40% must remain very dark uncluttered negative space suitable for adding real HTML title and buttons later. Do not add any new letters, logos, borders, buttons, symbols or UI. This is the same artwork, with just the title and interface completely erased. Keep full composition, no cropping, no redesign.
